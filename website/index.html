一个 open source 的学习项目

做 Aulos 是为了彻底搞清楚 AI Agent 的内部构造。项目基于 MiniCC——一个极简的 Claude Code 复刻——在其架构上扩展出三层上下文压缩、多 Agent、MCP 接入等能力。读懂 MiniCC，就读懂了 Aulos 的一半。

FEATURES

不是聊天玩具，是干活的工作台

从 Agent 内核到桌面界面，每一层都是为「把任务做完」设计的。

Agent 工具循环

模型自己决定调用哪个工具——读文件、改代码、跑命令，执行结果喂回继续思考，循环直到任务完成。流式输出，思考过程实时可见。

三层上下文压缩

MicroCompact → Session Memory → Full Compact，长对话不爆上下文。逐字锚点对冲摘要漂移，熔断降级保证压缩链路永不断供。

多 Agent 并行

主 Agent 派生多个子 Agent 并行干活：强模型做诊断与规划，便宜模型执行落地，省钱且不牺牲决策质量。

MCP 生态接入

stdio / http / sse 三种接法接入外部工具，兼容 Claude Code 技能包（SKILL.md）与配置格式；外部工具与内置工具同一套权限审批。

三级权限安全

plan 只读 → 工作区可写 → 全放行，越权操作弹窗审批。.git、~/.ssh 等敏感路径在任何模式下都强制人工确认，不可逆操作不静默。

桌面端 · 摸鱼电台

Tauri 2 桌面壳：设置页、多供应商切换、计划卡片；还有桌宠悬浮窗和内置电台（网易云 / B站），写码间隙来点音乐。

ARCHITECTURE

38k 行 Python，全部装在一个包里

CLI 与桌面端共享同一个 Agent 内核；模块边界清晰，读源码像读文档。
