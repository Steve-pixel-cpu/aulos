## 项目一句话

**Aulos** 是一个本地运行的 AI 编程 Agent：用自然语言下达任务，Agent 自主读文件、改代码、跑命令、查资料直到完成，提供终端 CLI 和桌面应用两种形态。基于开源项目 MiniCC 扩展而来（行级对比约 92% 为重写/新增），不绑定官方 API，任何兼容 Anthropic / OpenAI 协议的模型服务均可接入。

## 30 秒电梯陈述

> Aulos 是我深度参与开发的本地 AI 编程 Agent——类似 Claude Code 的开源实现，但不绑定官方 API。我负责从内核到桌面的完整工程：38k 行 Python 内核实现 Agent 自主工具循环、多 Agent 并行编排和三层上下文压缩；1,316 个测试用例构成分层质量保障；从 Electron 迁移到 Tauri 把安装包从 133MB 压到 28MB，并搭起三平台 CI 自动发版。这个项目里我踩过并发竞态、上下文溢出、跨平台打包等各类真实的坑，每个事故都沉淀成了回归测试和文档。

## 2 分钟展开版

> **背景**：AI Agent 要真正干活，核心难点不在「调用模型」，而在三件事：怎么让模型安全地操作真实系统、怎么在长对话里管理上下文、怎么保证一个非确定性的程序可以回归测试。Aulos 就是围绕这三个难点展开的。
>
> **核心设计**：Agent 主循环以「一致点」驱动——所有打断和收束检查都落在消息落定的位置，协议层面保证不会留下悬空的 tool_use；同步内核通过三个代理对象桥接到异步 Web 层，内核零改动同时服务 CLI 和桌面两种宿主；上下文用三层压缩（字符串替换 → 滚动摘要 → LLM 整段压缩），LLM 摘要的漂移用代码机械抽取的原文锚点对冲。
>
> **质量体系**：1,316 个单元测试之外，还有 Agent 级评测——被测对象是 subprocess 拉起的真实 CLI 入口，判分是确定性检查和 LLM 评委的双重门，`file_unchanged` 检查防止 Agent 改测试凑绿。每个真实事故都会沉淀为最小复现测试（回归钉），tests 目录里大量 docstring 直接以事故现场开头。
>
> **工程化**：单人项目做到了三平台 CI 自动发版、Tauri 自动更新、跨平台环境探测与自动降级（Wayland、VMware、GStreamer 缺件都有对应策略）。32 个版本 tag 记录了从「克隆造轮子」到「产品化」再到「工程化还债」的完整演进。
